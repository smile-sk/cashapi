# Настройка ВМ Ubuntu Server 24.04 - CashAPI

## Что уже готово (не надо заново)
- SSH-ключ сгенерирован, публичная часть лежит в `key.txt` (рядом с этим файлом).
- Bootstrap-скрипт: `scripts/bootstrap.sh` - делает всё сам (пользователь `cody`,
  sudo, ключ, Docker, ufw).

## Как запустить (две команды с твоей Windows)

Открой PowerShell в папке проекта:
```powershell
cd D:\Documents\Projects\CashAPI
```

**Команда 1** - скопировать скрипт на сервер (`<user>` - имя пользователя, который
создавался при установке Ubuntu на ВМ; если не помнишь - глянь в консоли ВМ через `whoami`):
```powershell
scp .\scripts\bootstrap.sh <user>@x.x.x.x:~/
```

**Команда 2** - выполнить его на сервере (спросит пароль `<user>`):
```powershell
ssh <user>@x.x.x.x "sudo bash ~/bootstrap.sh"
```

Скрипт сам: обновит пакеты, создаст пользователя `cody` (полные права sudo,
вход только по ключу), положит ключ из `key.txt` в `authorized_keys`, поставит
Docker + Python + git + ufw, включит фаервол (наружу только SSH).

## Проверка (после выполнения скрипта)
```powershell
ssh cody@x.x.x.x
```
Должно зайти БЕЗ пароля (по ключу). Если зашло - всё готово, дальше я дам
команды на разворачивание проекта (сканер + FastAPI-аптека).

## Если что-то не так
- `scp` не видит файл - убедись, что ты в папке проекта (`pwd`).
- Ошибка «Permission denied» при scp - проверь имя `<user>` и пароль.
- Скрипт уже запускался ранее - он идемпотентный, можно гонять повторно.
