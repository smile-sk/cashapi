# cody-scanner - разведчик «лекарств»

Асинхронный сканер-разведчик: ищет, где на рынке API есть спрос и пустые
ниши, чтобы пополнять ассортимент аптеки.

- `scanner.py` - каркас: aiohttp, пул воркеров, SQLite (WAL).
- `plugins/*.py` - по одному плагину на источник.
- `config.json` - таргеты, воркеры, база.
- `scan.db` - результаты: статус, задержка, мета.
- `scan_report_2026-08-19.md` - первый отчёт с кандидатами в таблетки.

## Плагины (рабочие)
| Плагин | Источник | Что даёт |
|---|---|---|
| `apis_guru` | api.apis.guru/v2/list.json (2529 API) | счётчик API по темам-утилитам - где спрос, где пусто |
| `public_apis` | public-apis на GitHub (1702 API) | категории и число API в каждой |
| `rapidapi_categories` | sitemap-category.xml | карта 48 категорий маркетплейса (сегменты спроса) |

## Запуск
```
pip install aiohttp
python scanner.py
```
В фоне на сервере:
```
nohup python3 scanner.py >> scan.log 2>&1 &
```
(или cron - решим, когда понадобится регулярность)

## Добавить источник
1. `plugins/myplatform.py` с `async def probe(session, cfg) -> {"status": int, "meta": {...}}`.
2. Таргет в `config.json`.
3. `python scanner.py`.

## Ограничения
RapidAPI-поиск по запросам скрейпить напрямую нельзя (SPA, всё грузится JS).
Поэтому берём официальный sitemap категорий, а конкуренцию по конкретным
запросам смотрим браузером вручную при выборе новой таблетки.
